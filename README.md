# Learning-path-generator
This repository contains the source code for an Autonomous Learning Path Generator, a multi-agent AI system designed to create personalized, structured roadmaps for any topic.
🚀 Autonomous Learning Path GeneratorA high-performance, multi-agent AI system designed to transform any learning goal into a structured, actionable roadmap. This application orchestrates a team of specialized AI agents to assess user skills, curate high-quality resources, and provide real-time mentoring through an adaptive interface.  
🧠 The Multi-Agent ArchitectureThe system utilizes four distinct AI agents that collaborate to build your personalized curriculum:  🔍 Skill Assessor: Analyzes your current expertise level and specific learning goals to set a baseline.  
🗺️ Roadmap Builder: Architectures a three-phase curriculum with clear objectives and time-bound milestones.  📚 Resource Curator: Scours the web to link specific videos, articles, projects, and quizzes to every task.  
🎯 Progress Coach: Monitors your completion rate and provides adaptive strategy shifts to keep you on track.  
✨ Key FeaturesPersonalized Roadmap EngineGenerates a custom 3-Phase structure (Foundations, Core Skills, and Mastery/Portfolio) based on your available hours per week.  Includes a "Watch on YouTube" integration for every video task, generating precise search queries for instant learning. 
AI Mentor ChatSwitch between five distinct AI personas for real-time support:  Coach: High-energy and goal-oriented.  Socratic: Guides you via critical thinking and questions.  Drill Sergeant: No-nonsense accountability.  Friend: Casual and low-pressure support.  Expert: Deep technical insights and industry context. 
Adaptive Learning InterfaceProgress Dashboard: Visualizes your journey with overall and phase-specific completion percentages.  Path Adaptation: A dedicated "Adapt Path" feature that provides custom strategic advice based on your current progress state (e.g., preventing plateaus or handling burnout). 
Smart Suggestions: Context-aware chat prompts that change as you progress through the curriculum. 
🛠️ Technical StackFrontend: HTML5, CSS3, and Vanilla JavaScript.  Styling: Modern Glassmorphism UI with a custom "Space Grotesk" and "Outfit" typography stack.  AI Integration: Designed to interface with Claude AI (Anthropic) via API, with a robust offline fallback logic for consistent performance. 
Responsive Design: Fully optimized for mobile with touch-target optimization and fluid layouts
